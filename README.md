# 异界问道

《异界问道》是一款以文字叙事为主的单机异界修仙模拟器，适配桌面和手机浏览器。

玩家将以受“界蚀印”侵蚀的散修身份坠入异界，模拟一段没有预设目标的异界人生。时间以天推进，每次修炼、探索、采药、交易或移动都会留下新的经历与因果；筑基只是可选择追求的修行节点，不是必须完成的结局。

## 游戏特色

- 三选一随机命格：每局组合不同的出身、灵根和天赋
- 程序化世界地图：每次轮回随机抽取地点、调整布局并生成额外道路
- 开局世界设定：可选择小型、标准或广阔世界，也可自定义 5 至 100 个地点，并调整清平、常态或险世的凶险程度
- 可拖动舆图：地点较多时可以拖拽、缩放地图视口浏览完整疆域，地点会按规模自动拉开间距
- 地域行动差异：沿道路移动，在不同地点执行探索、采药、炼丹或交易等地点行动
- 分层行动系统：闭关吐纳、静养心神等固有行动随身可用；探索、采药、炼丹和交易由地点提供
- 地点规则差异：静修地、聚落、灵矿、学宫、险地和界隙等地点拥有不同的修炼加成、资源效率或行动禁制
- 异界人物群像：每局按世界种子生成不同身份、境界和战力的 NPC，可通过闲谈、赠礼、切磋和相助建立从陌生到莫逆的关系
- 六大修行境界各有九层：炼气、筑基、金丹、元婴、化神、合体；突破合体九层后羽化飞升并结束此世
- 47 个文字事件：包含途中突发状况、资源取舍、属性判定和多结果冲突
- 模糊天机提示：展示“凶险”“稳妥”等档位，不直接透露精确概率
- 人生自然收束：角色寿元耗尽或体力归零时结束此世，筑基不会强制结束游戏
- 轮回见闻：结局后解锁新的出身、天赋和事件，不提供永久数值碾压
- 本地存档：自动保存当前进度，并支持 JSON 导入和导出
- 可选 AI 模式：支持 OpenAI 兼容与 Claude Messages 格式，可获取模型列表并让 AI 裁定行动、行途、NPC 交往和事件结果
- 响应式界面：桌面使用三栏布局，手机使用单列内容和底部导航
- 人生属性：寿元与年龄决定自然寿终，体力归零会结束此世；灵力、心境、修为持续变化，战力影响战斗事件的成败与受伤程度

## 环境要求

- Node.js 18.17 或更高版本
- npm 9 或更高版本
- Chrome、Edge、Firefox 或 Safari 的较新版本

## 快速开始

在 PowerShell 中进入项目并安装依赖：

```powershell
cd D:\Developer\AnotherWorld
npm install
```

启动开发服务器：

```powershell
npm run dev
```

终端会显示访问地址，通常为：

```text
http://localhost:5173
```

使用同一局域网内的手机测试时，可以运行：

```powershell
npm run dev -- --host 0.0.0.0
```

随后在手机浏览器中访问终端显示的 Network 地址。Windows 防火墙可能会要求允许 Node.js 访问专用网络。

## 关闭服务器

在运行开发服务器的终端窗口中按：

```text
Ctrl + C
```

如果服务器在后台运行，可以按端口找到并关闭进程：

```powershell
$gamePid = (Get-NetTCPConnection -LocalPort 5173 -State Listen).OwningProcess
Stop-Process -Id $gamePid
```

若启动时指定了其他端口，请将命令中的 `5173` 换成实际端口。

## 基本玩法

1. 输入姓名，并从三组随机命格中选择一组。
2. 在“行旅”页阅读主角的人生历程；具体行动请打开“异界舆图”。
3. 在地图页查看当前地点的规则，右键当前位置卡片打开行动菜单（手机端长按），或沿相连道路前往聚落、药谷、灵矿、险地、学宫、宗门或界隙。
4. 移动会消耗一天与少量灵力；地点行动会随所在地变化，部分险地禁止休息，灵脉和学宫则会提高修炼效率。
5. 途中可能遭遇灵雨、商队、妖兽、塌方或界隙等突发事件。
6. 遇到异闻时选择处理方式；不同属性、状态和气运会影响结果。
7. 修为达到当前上限后尝试突破，可选择服用破障丹提高成功档位。
8. 没有必须完成的目标；你可以追求筑基，也可以在异界经营自己的生活。
9. 结局会生成生涯评分并获得轮回见闻，用于解锁后续内容。

游戏会在每次行动、事件选择和突破后自动保存。不要在多个标签页中同时操作同一份存档，否则最后写入的标签页会覆盖之前的进度。

## 存档说明

存档保存在当前浏览器的 `localStorage` 中，不会自动同步到其他设备或浏览器。

游戏内的“存档管理”提供：

- 导出存档：下载包含当前周目和轮回见闻的 JSON 文件
- 导入存档：校验并载入此前导出的 JSON 文件
- 舍弃此世：清除当前周目，但保留已经获得的轮回见闻

清除浏览器站点数据会同时删除本地存档。更换设备或浏览器前应先导出存档。

## AI 接口与跨域

游戏设置中的 AI 请求会优先发送到当前站点的 `/api/ai-proxy` 同源代理，再由 Vite 开发/预览服务器转发到你填写的 API 地址。这样常见的 OpenAI 兼容接口或模型网关即使没有浏览器 CORS 响应头，也可以在本地使用。

修改代理配置后请重启开发服务器：

```powershell
Ctrl + C
npm run dev
```

生产部署到纯静态站点时，需要在站点服务器上配置同名的 `/api/ai-proxy` 转发接口；否则浏览器只能直连第三方接口，而第三方未开放 CORS 时仍会被浏览器拦截。API Key 只保存在当前浏览器的本地设置中，但通过代理时仍应只使用你信任的服务器。

## 构建与部署

生成生产版本：

```powershell
npm run build
```

构建产物位于 `dist` 目录，可以部署到任意静态站点服务，例如 Nginx、GitHub Pages、Cloudflare Pages 或 Netlify。游戏没有后端服务和数据库依赖。

在本地预览生产构建：

```powershell
npx vite preview
```

### GitHub Pages

项目已包含 `.github/workflows/deploy-pages.yml`。将代码推送到 GitHub 仓库的 `main` 或 `master` 分支后，GitHub Actions 会自动构建并发布到 Pages。

首次使用时，在仓库的 `Settings → Pages` 中将发布来源设为 `GitHub Actions`。项目站点地址通常为 `https://用户名.github.io/仓库名/`。

GitHub Pages 只提供静态文件，不包含 `/api/ai-proxy` 后端代理。部署后若 AI 服务没有开放 CORS，仍需将 AI 接口改为允许浏览器跨域，或另行部署同源代理。

## 扩展内容

主要内容集中在 `src/game/data/`：

- 在 `ORIGINS`、`SPIRIT_ROOTS` 和 `TALENTS` 中扩展角色命格
- 在 `EVENTS` 中添加声明式事件、选项、条件和效果
- 在 `ACTIONS` 中调整行动描述与事件触发概率
- 在 `LOCATION_POOLS` 中新增地点类型、地点行动和地点规则
- 在 `NPC_IDENTITIES`、`NPC_INTERACTIONS` 中扩展人物身份与关系互动

核心数值与状态流转位于 `src/game/engine.ts`。随机行为使用可复现的种子，因此修改判定逻辑后应同步运行测试。

## 常见问题

### 端口已被占用

Vite 会自动选择其他端口，也可以手动指定：

```powershell
npm run dev -- --port 4173
```

### 页面打开后是空白

确认终端中的开发服务器仍在运行，并优先使用终端显示的地址。然后重新执行：

```powershell
npm install
npm run build
```

### 手机无法访问

确认使用了 `--host 0.0.0.0`，手机与电脑处于同一局域网，并允许 Node.js 通过 Windows 防火墙的专用网络规则。
